## 🛠️ Tecnologias Utilizadas

* **Front-end**: HTML5 Semântico, CSS3 (Design Orgânico e Responsivo), JavaScript ES6+
* **Recursos PWA**: Service Worker (`sw.js`), Web App Manifest (`manifest.json`)
* **Acessibilidade & Acolhimento**: Web Speech API (Comandos de Voz), Exercício Respiratório 4-4-4 (Método de Ancoragem)
* **Gestão e Controle**: Figma (UI/UX), Trello (Metodologia Ágil / SCRUM), Git & GitHub (Versionamento)
